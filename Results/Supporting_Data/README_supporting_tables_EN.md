# Supporting tables for the Anza manuscript

These CSV files are derived from saved analysis outputs. They do not include the raw survey XYZ or full satellite/model grids. Grain-size values are scenarios, not local measurements. HR-OC is satellite-derived, not independent field validation. The mobility score is conditional on the selected equations, regional forcing products, local hydrographic zero, and support rules.

- Table S2: the 73 unique Sentinel-2 catalog dates, product-level cloud metadata, and ROI-QA flag.
- Table S3: provenance and limits for six D50 scenarios.
- Table S4: continuous-score sensitivity results for the 11 ROI-QA dates.
- Table S5: HR-OC water-support summaries.
- Table S6: fixed depth-support records.
- Tables S7-S8: within-cell wave-response robustness and lag-window models; confidence intervals crossing zero indicate imprecise associations.

Do not describe any table as measured sediment flux.
